# Créditos dos vídeos

Os vídeos desta pasta são recortes da base **MINDS-Libras Dataset (RGB-D sensor data)**, publicada no Zenodo sob a licença [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

- Fonte: https://zenodo.org/records/4322984
- DOI: https://doi.org/10.5281/zenodo.4322984

**Alterações feitas:** redução de resolução, recompressão e remoção de áudio e dos dados de profundidade. Os sinais não foram editados.
