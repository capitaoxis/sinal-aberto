# De onde roubamos

Inspirado em *Roube como um artista*, de Austin Kleon: estudar a fundo, roubar de muitos, dar crédito e transformar.

## Usamos no projeto

| O quê | Para quê | Licença |
|---|---|---|
| [MINDS-Libras](https://zenodo.org/records/4322984) ([DOI](https://doi.org/10.5281/zenodo.4322984)) | Vídeos das lições e treino do modelo | CC BY 4.0 |
| [VLibras](https://github.com/spbgovbr-vlibras) | Avatar 3D do governo federal para palavras fora das lições, carregado dos servidores oficiais só quando a pessoa pede | Código LGPL-3.0. A licença dos avatares e do dicionário não está informada, por isso não copiamos esses arquivos |
| [Atkinson Hyperlegible](https://fonts.google.com/specimen/Atkinson+Hyperlegible) | Fonte feita para leitura fácil | SIL OFL 1.1 |

## Só a ideia, sem copiar código ou conteúdo

| De onde | A ideia |

| Duolingo | Lições curtas com retorno na hora. Nome e visual são nossos |

| *Roube como um artista* | Dar crédito e mostrar o trabalho enquanto ele acontece |
